# AGENTS.md - Hugo Theme hugo-onix-theme

Minimalist Hugo blog theme. Fork of `vaga/hugo-theme-m10c`; the theme id is `hugo-onix-theme` (`theme.toml`). Icon data namespace is `onix`.

## Commands
- **Build example site**: `hugo --source exampleSite` (requires **hugo_extended** >= 0.158.0 per `config.toml`; `hugo` is not vendored by this repo). Verify with `hugo --source exampleSite --panicOnWarning`.
- **Regenerate icons**: `scripts/update_icons.sh` (uses yarn), or from `scripts/icons/`: `yarn install && yarn build`. A committed `yarn.lock` exists, so prefer yarn over npm. Node **>= 20.11** (`import.meta.dirname`).
- **No tests, lint, typecheck, formatting, or CI exist.** Building the site is the only verification; do not invent commands.

## Gotchas
- `exampleSite/config.toml` sets `theme = "hugo-onix-theme"` but the checkout dir is `hugo-monokai-theme`; building the example site fails unless the dir is named `hugo-onix-theme` or that line is changed.
- `assets/css/main.scss` is a **Go template, not plain SCSS**: it interpolates `.Site.Params.colorScheme` to pick a scheme file via `@import`, and is rendered via `resources.ExecuteAsTemplate` before `css.Sass` (`layouts/baseof.html:11`). Do not compile it with sass directly.
- `data/onix/icons.json` (~3500 entries) is generated by `scripts/icons/update_icons.js`; never hand-edit it. `layouts/_partials/icon.html` falls back to a generic link icon for unknown names.

## Layouts (post-0.146)
- Uses the Hugo 0.146+ template layout: page templates at `layouts/*.html` (`baseof.html`, `list.html`, `single.html`, `taxonomy.html`, `404.html`) and partials in `layouts/_partials/`. Do not reintroduce `layouts/_default/` or `layouts/partials/`.
- `_internal/*` templates are gone; call built-ins as partials (e.g. `partial "opengraph.html"`, `"google_analytics.html"`). Disqus and Twitter Cards have been removed.
- Prefer current Hugo APIs: use `hugo.Data` (not `.Site.Data`) and `.Site.Language.Locale` (not `.Site.LanguageCode`); both older names warn on >= 0.156/0.158 and fail under `--panicOnWarning`.

## Color schemes
- Each scheme is its own SCSS file under `assets/css/schemes/*.scss` defining the five variables `$darkest-color`, `$dark-color`, `$light-color`, `$lightest-color`, `$primary-color`.
- Selected via `params.colorScheme` (default `monokai-pro-ristretto`; alternative `gruvbox-dark-soft`).

## Conventions
- SCSS: `assets/css/_base.scss` plus `assets/css/components/_*.scss`, all imported from `main.scss`. Per-project overrides go in a site's `assets/css/_extra.scss`; the theme's own `_extra.scss` must stay comment-only.
- Icons: Feather names used bare (`home`, `calendar`); Simple Icons prefixed with `brand-` (`brand-github`, `brand-x`).
- `.editorconfig`: 2-space indent, LF, final newline, no trailing whitespace (except `.md`).
- Site params driving the theme: `author`, `description`, `avatar`, `favicon`, `menu_item_separator`, `colorScheme`; `[menu.main]` items use `identifier`/`name`/`url`/`weight`; `params.social[]` uses `icon`/`name`/`url`.
